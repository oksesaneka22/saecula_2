# Saecula

**Saecula** — це 2D top-down пісочниця з видом зверху, яка поєднує пряме виживання/добування ресурсів та симулятор автономного поселення (Minecolonies-like) із поступовим переходом між технологічними епохами (від Кам'яного віку до Середньовіччя).

Проект розробляється на рушії **Godot Engine 4.x** (GDScript 2.0 зі строгою типізацією).

---

## 🖥️ Системні вимоги та налаштування екрану

- **Рушій:** [Godot Engine 4.x](https://godotengine.org/) (рекомендовано Godot 4.3 або новіше, стандартна версія).
- **Підтримувані роздільні здатності:**
  - **1920x1080 (Full HD, 16:9)** — базова роздільна здатність вікна/в'юпорту.
  - **2560x1440 (2K QHD, 16:9)** — нативна підтримка без розмиття.
- **Рендерер:** Compatibility (`gl_compatibility`) для максимальної стабільності та продуктивності.

---

## 🚀 Як запустити проект

### Спосіб 1: Через редактор Godot (GUI)

1. Завантажте та запустіть **Godot Engine 4.x**.
2. У вікні вибору проектів натисніть кнопку **Import** (Імпортувати).
3. Виберіть файл `project.godot` у кореневій папці цього репозиторію.
4. Натисніть **Import & Edit** (Імпортувати та редагувати).
5. Для запуску гри у правому верхньому кутку редактора натисніть кнопку **Run Project** (або гарячу клавішу `F5`).

---

### Спосіб 2: Через командний рядок (CLI)

Якщо у вас встановлено консольну або стандартну версію Godot:

#### Windows (PowerShell / Command Prompt):
```powershell
# Запуск гри з вікном:
godot --path "шлях\до\папки\saecula_2"

# Або прямим викликом виконуваного файлу Godot:
& "C:\Users\<ВашКористувач>\Downloads\Godot_v4.x_win64.exe" --path "."
```

#### Запуск у безголовому режимі (для перевірки та тестів без UI):
```powershell
godot --headless --path "." --quit
```

## 🎮 Базове керування (Controls)

| Дія | Клавіша | Опис |
| :--- | :--- | :--- |
| **Рух** | `W`, `A`, `S`, `D` або `Стрілки` | 8-напрямний плавний рух персонажа |
| **Взаємодія** | `E` | Збір ресурсів, вхід у будівлю, розмова |
| **Режим поселення** | `Tab` | Перемикання в режим керування поселенням зі сповільненим часом (`colony_mode_toggle`) |
| **Інвентар** | `I` | Відкрити/закрити інтерфейс інвентаря (`inventory_toggle`) |
| **Скасування** | `Escape` | Закрити меню, скасувати розміщення будівлі або вийти на паузу |
| **Зум камери** | `Коліщатко миші` | Наближення / віддалення огляду (`zoom_in`, `zoom_out`) |
| **Основна дія** | `Ліва кнопка миші` | Атака, вибір, розміщення будівлі |
| **Додаткова дія** | `Права кнопка миші` | Контекстне меню, скасування вибору |
| **Швидкий доступ** | `1` .. `9` | Вибір слота на панелі швидкого доступу (Hotbar) |

> *Примітка:* Керування використовує фізичні скан-коди клавіш (`physical_keycode`), тому клавіші `WASD` працюють коректно незалежно від поточної мовної розкладки клавіатури.
