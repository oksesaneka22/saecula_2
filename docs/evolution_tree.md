# EPOCHES
### Епоха 1: Первісна доба (Виживання та Базовий збір)

**1.1. Доба Іскри (Палеоліт)**

- **Ключові ресурси:** Хмиз, суха трава, кремній, галька, сире м'ясо/ягоди.
    
- **Технологічний прорив:** Відкриття вогню тертям/кременем.
    
- **Будівлі:** Вогнище (перша «Ратуша», відганяє диких звірів), накриття з гілок (спальне місце).
    
- **Поселенці:** Ручний збір без інструментів. Поселенці не вміють нічого зберігати, їдять знахідки на місці або зносять до вогнища.
    

**1.2. Доба Обробленого Каменю (Неоліт)**

- **Ключові ресурси:** Обтесаний камінь, колоди, глина, рослинні волокна.
    
- **Технологічний прорив:** Прив'язування каменю до держака (примітивні сокири/молотила), ліплення посуду.
    
- **Будівлі:** Землянка, сушарка для м'яса, яма для зберігання зерна, гончарне багаття.
    
- **Поселенці:** Поява першої спеціалізації — збирач, рубач, охоронець вогню.
    

### Епоха 2: Доба Ремісництва (Метал та Механіка)

**2.1. Мідно-Бронзовий Світанок**

- **Ключові ресурси:** Мідна та олов'яна руда, деревне вугілля, бронзові зливки, шкіра.
    
- **Технологічний прорив:** Лиття у форми, колесо, тяглова сила тварин.
    
- **Будівлі:** Плавильна яма, майстерня ливарника, загін для волів, дерев'яний віз (транспортування пачок ресурсів).
    
- **Поселенці:** Робітники перестають носити по 1 предмету в руках; з'являються візки, які збільшують вантажопідйомність у 5–10 разів.
    

**2.2. Залізо та Гідравліка**

- **Ключові ресурси:** Залізна руда, вапняк, обтесані кам'яні блоки, загартована сталь.
    
- **Технологічний прорив:** Сиродутне горно, ковальське зварювання, водяне колесо.
    
- **Будівлі:** Водяний млин (механічна енергія для жорнів чи ковальського молота), кузня, кам'яні склади, сторожова вежа.
    
- **Поселенці:** Поділ праці на чорнову (добувачі руди, вугільники) та кваліфіковану (ковалі, каменярі).
    

### Епоха 3: Індустріальна доба (Пара та Електрика)

**3.1. Доба Чавуну та Пари**

- **Ключові ресурси:** Кам'яне вугілля, чавун, очищена вода, мастила, сталевий прокат.
    
- **Технологічний прорив:** Паровий двигун, рейковий транспорт, стандартизація деталей.
    
- **Будівлі:** Паровий котел, вугільна шахта з помпою, котельня, вузькоколійка для вагонеток.
    
- **Поселенці:** Робітники стають операторами машин. Замість біганини з возами ресурси між районами возять парові дрезини.
    

**3.2. Доба Електрифікації та Нафтохімії**

- **Ключові ресурси:** Сира нафта, мідний дріт, гума, бензин/дизель, бетон.
    
- **Технологічний прорив:** Генератор змінного струму, двигун внутрішнього згоряння (ДВЗ), перегонка нафти.
    
- **Будівлі:** Дизельна електростанція, нафтова вишка, ЛЕП, механізований конвеєрний цех.
    
- **Поселенці:** З'являється концепція енергомережі поселення: без живлення фабрики зупиняються, поселенцям потрібне електричне світло для нічної зміни.
    

### Епоха 4: Технологічна та Сучасна доба (Автоматизація і Мережі)

**4.1. Кремнієва революція (Напівпровідники та Рання автоматизація)**

- **Ключові ресурси:** Очищений кремній, алюміній, текстоліт, базові мікросхеми, пластик.
    
- **Технологічний прорив:** Транзистори, числове програмне керування (ЧПК/CNC), релейні логічні плати.
    
- **Будівлі:** Хімічний комбінат, завод мікроелектроніки, автоматизована сортувальна лінія.
    
- **Поселенці:** Колоністи майже повністю виходять із сектору важкої праці: верстати з ЧПК виготовляють деталі самі, люди лише подають сировину та ремонтують механізми.
    

**4.2. Інформаційна та Мережева епоха**

- **Ключові ресурси:** Рідкісноземельні метали (літій, неодим), оптоволокно, серверні стійки, акумулятори.
    
- **Технологічний прорив:** Інтернет/LAN-протоколи управління, алгоритми оптимізації, зелена енергетика.
    
- **Будівлі:** Серверний дата-центр, сонячні/вітропарки, док-станції логістичних дронів, літієвий комбінат.
    
- **Поселенці:** Запровадження дронів: дрібні вантажі переносяться повітрям напряму зі складів до верстатів. Сервери генерують очки «Алгоритмів», що прискорюють будь-які дослідження.
    

**4.3. Автономна сучасність (Кібернетика та Синтез)**

- **Ключові ресурси:** Вуглецеві нанотрубки, титанові сплави, процесори нейромереж, синтетичне паливо, дейтерій.
    
- **Технологічний прорив:** Повноцінна промислова робототехніка, мініатюрні ядерні/термоядерні реактори, адаптивний 3D-друк.
    
- **Будівлі:** 3D-фабрика будівель (принтер зводить споруду без участі людей), автоматизовані андроїд-станції, модульний реактор.
    
- **Поселенці:** Фізична праця людей зникає на 100%. Гравець більше не керує робітниками-людьми — всю рутину виконують андроїди та безпілотники. Люди стають «елітою поселення» (вченими, інженерами, адміністраторами), чиї потреби тепер зводяться до високого рівня комфорту, науки та безпеки.
